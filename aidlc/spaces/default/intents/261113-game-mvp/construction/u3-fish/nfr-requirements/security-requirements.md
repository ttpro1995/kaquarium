# Security Requirements — u3-fish

> Upstream: `functional-design/functional-spec.md` (W12–W15), `rules.md` (BR10–BR11), `requirements.md` (NFR3, NFR4, NFR5), `contract-summary.md` (C2 determinism rule, C6 import pipeline). Answers from `nfr-requirements-questions.md` (Q1–Q4 all A).
> Threat posture: same as U2 (browser-local, no network/auth/PII/secrets). Fish-specific surfaces: genome records (opaque maps, validated never executed), death-cause strings (display only), per-fish numeric ranges.

| ID | Requirement | Source | Verification |
|---|---|---|---|
| NFR3.1 | Life-event determinism: RNG-driven events (sex 50/50, juvenile size, per-locus genome rolls) draw only through `ctx.rng` while iterating fish in the store's stable key order — no per-tick sort (insertion order is deterministic for a given seed + command sequence, including save/load round-trips, and the replay test pins it). Age-driven transitions (old-age death per BR10.6) are explicitly exempt — deterministic with no RNG. Clutch/cohort draws belong to U5 (C1 FryCohort ownership) and are specified in U5's NFR pass, not here. | NFR3 | Golden replay test: scripted birth-death-maturity sequence matches stored state. |
| NFR4.1 | Fish migration, single owner: the v1 → v2 migration fills `Fish.stunted = false` for records lacking it (register row added to the U2 breaking-change register — the field lands with U5's data completion but the schema bump is shared, so one migration owns all absent-field filling; no load-defaulting path). Genome records validate as records only. | NFR4 | v1 fixture → migrated Fish equal fresh saves; post-migration structural validation (U2 NFR4.3, extended to `Fish.genome` is-record) rejects non-record genomes INVALID_SHAPE; U3 consumer guards (`spawnFish`/`inheritGenome`) re-validate at use. |
| NFR4.2 | U3 never reads raw save payloads; all Fish state enters through the C6 import pipeline plus the U2-owned NFR4.3 bounded import barrier (pre-parse size gate, count caps, chemistry ranges, post-migration structural validation). Death causes are display strings, never executed. | NFR4 | Import suite rejects malformed Fish without touching the current save. |
| NFR5.1 | Fish logic is test-first (TDD) with the 80% line-coverage floor and CI gate; growth-curve, stressor, death-cause, and genome-roll paths carry boundary tests. | NFR5 | Coverage report + CI block on failure. |
