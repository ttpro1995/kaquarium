# Security Requirements — u7-presentation

> Upstream: `functional-design/functional-spec.md` (W38, W43–W47), `frontend-components.md`, `requirements.md` (NFR2, NFR3, NFR4, NFR5), `contract-summary.md` (C5 boot validation, C6 import pipeline). Answers from `nfr-requirements-questions.md` (Q2–Q3 A).
> Threat posture: browser-local, no network/auth/PII/secrets. U7-specific surfaces: save import file handling (user-supplied JSON), external species data (never executed), settings persistence, fault surfacing (no state rollback from UI).

| ID | Requirement | Source | Verification |
|---|---|---|---|
| NFR2.1 | WCAG 2.1 AA shell: every action keyboard-reachable with visible focus and Esc-to-close dialogs — including canvas-anchored actions, whose keyboard path is the Roster panel (focusable rows → same FishPanel as a canvas click, W39); status never by colour alone (icon + text/number); notifications polite via aria-live, criticals assertive; touch targets ≥ 44px; text scales with system settings (holds at 200% zoom); `reducedMotion` and `autoPauseCritical` honoured everywhere. | NFR2 | axe-core audit scoped to the shell DOM (canvas pixels carry no DOM semantics and are excluded by design): zero serious/critical violations in CI; keyboard-only walkthrough of every tab/dialog plus fish selection via Roster; 200% zoom layout check (no clipped targets); reduced-motion snapshot (ambient frozen); manual screen-reader pass at milestones. |
| NFR3.1 | Render path needs no determinism guarantee: sprite positions/steering/particles are visual-only, seeded per mount from `crypto.getRandomValues` (local entropy — identical restart motion is accepted as harmless), and never serialized — replay determinism covers the sim only. The seeded-stream ban covers sim systems only: the renderer must never consume `ctx.rng` (that would desync the sim stream) but is free to use local entropy; the lint rule enforcing the ban applies to sim packages, not renderer modules. | NFR3 | Codegen check: no `ctx.rng` import in renderer modules; replay test output identical with renderer on/off. |
| NFR4.1 | Settings (`reducedMotion`, `autoPauseCritical`, `volume`) persist through the C6 save envelope — defaults `false` / `true` / `{ master: 0.8, sfx: 0.8 }` per built `defaultSettings()` — and round-trip with those defaults on old saves; import validation failures surface named errors without touching the current save (W44). | NFR4 | Save/load round-trip with non-default settings; v1 envelope fixture with settings fields removed gains the documented defaults. |
| NFR5.1 | Shell logic is test-first (TDD) with the 80% line-coverage floor and CI gate; command-dispatch wiring, selector subscriptions, and error surfacing carry tests. Renderer visuals are covered by snapshot + soak tests, not line coverage: the snapshot subject is the sprite catalog — one render per species genome variant from a frozen catalogue fixture in headless Chromium, pixel-compared at ≤ 0.1% differing pixels — plus shell DOM snapshots for panels; the renderer metric is 100% sprite-builder branch coverage via the catalog fixture plus the NFR1 soak. | NFR5 | Coverage report + CI block on failure; axe-core + keyboard walkthrough in CI; catalog snapshot suite green. |
