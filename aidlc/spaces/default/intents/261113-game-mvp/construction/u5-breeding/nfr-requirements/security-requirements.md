# Security Requirements — u5-breeding

> Upstream: `functional-design/functional-spec.md` (W21–W25), `rules.md` (BR14–BR15), `requirements.md` (NFR3, NFR4, NFR5), `contract-summary.md` (C2 determinism rule, C4 event catalogue, C6 import pipeline). Answers from `nfr-requirements-questions.md` (Q1–Q4 all A).
> Threat posture: same as U2–U4 (browser-local, no network/auth/PII/secrets). Breeding-specific surfaces: pair-bond integrity (re-pair guards), grading capacity gate (TANK_FULL cannot be bypassed), cohort counts as import-bounded integers.

| ID | Requirement | Source | Verification |
|---|---|---|---|
| NFR3.1 | Spawn determinism (owns the draws deferred from U3 NFR): clutch/cohort draws and per-pair attempt rolls draw only through `ctx.rng` while iterating pairs/cohorts in the store's stable key order — no per-tick sort. Stable means: insertion order is deterministic for a given seed + command sequence including save/load round-trips (Record string-key order survives JSON serialization; every mutation flows through commands/systems), and the golden replay test pins it. Replay reproduces every conception, brood size, fertility roll, and hatch. | NFR3 | Golden replay test: scripted pairing → spawn → hatch → grade sequence matches stored state. |
| NFR4.1 | Breeding-state migration, single owner: the v1 → v2 migration adds absent `GameState.pairs` as an empty record and fills cohort `firstFoodDays`/`lastFryFedDay` (with the U4 rows) — register rows amended into the U2 breaking-change register; no load-defaulting path. A pre-U5 save therefore loads with no pairs and no phantom pregnancies. | NFR4 | v1 fixture → migrated save has `pairs: {}` and zeroed counters; grading on migrated state behaves as a fresh save. |
| NFR4.2 | U5 never reads raw save payloads; all breeding state enters through the C6 import pipeline plus the U2-owned NFR4.3 bounded import barrier, with these explicit U5 inputs to that barrier (owner: U1 kernel; enforced post-migration, pre-runtime, INVALID_SHAPE on violation): per-pair — state enum (paired/gravid/cooling), readyDay integer ≥ 0, speciesId/femaleId/maleId non-empty strings; per-cohort — stage enum (eggs/fry), count integer ≥ 0, ageDays number ≥ 0 (fractional mid-day accrual per W24 — NOT integer), hatchDay integer ≥ 0, genomePool is-record; pairs ≤ 500 (consistent with the O(pairs + cohorts) scan and the fish-1000 cap). | NFR4 | Import suite rejects malformed breeding state without touching the current save, including hand-stamped fixtures (unknown pair state, negative readyDay, 501st pair, negative cohort count). |
| NFR5.1 | Breeding logic is test-first (TDD) with the 80% line-coverage floor and CI gate; attempt-gate, clutch-scale, survival-decay, and grading-capacity paths carry boundary tests. | NFR5 | Coverage report + CI block on failure. |
